Hospital Management System

Simple and efficient hospital management solution

Project Overview

Hospital Management System is a web-based project designed to manage hospital information in an organized and user-friendly way. It can be used to manage patients, doctors and appointments.

Patient Management

Manage patient information and maintain patient records.

Doctor Management

Store and manage doctor information and details.

Appointment Management

Manage appointments between doctors and patients.

Dashboard

Display important hospital information in one place.

Technologies Used

HTML CSS JavaScript Python Django MySQL
